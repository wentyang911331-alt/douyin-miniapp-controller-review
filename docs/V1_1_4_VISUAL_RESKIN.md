# 1.1.4 视觉换肤说明

## 版本定位

1.1.4 是基于 `v1.1.2` 的 UI 视觉换肤版本。

`v1.1.3` 保留为闲置历史阶段，不继续推进，也不作为本次实现基线。

## 当前状态

- 开发分支：`codex/v1.1.4-visual-reskin-from-v1.1.2`
- 代码基线：`v1.1.2`
- 当前动作：根据已确认口径，将 UI 交付包落地到原生抖音小程序页面
- 当前禁止动作：不得改核心功能、数据结构、交互逻辑、模块顺序和业务结论

## UI 交付包口径

- 交付包名称：`抖音小程序1.1.4 UI包.zip`
- 交付包基准：UI 侧声明基于 `v1.1.2`
- 交付包内容：静态 HTML/CSS 状态稿、design tokens、SVG 图标、状态截图
- 目标：还原 UI 包视觉，而不是重新设计页面

## 修改范围

允许修改：

- 颜色
- 字号、字重、行高
- 间距
- 圆角
- 边框
- 阴影
- 图标风格
- 线条粗细
- 背景层级
- 其他纯视觉表现

不允许修改：

- 功能
- 数据结构
- 交互逻辑
- 排序逻辑
- 表格字段含义
- 页面模块顺序
- 业务结论
- 后端接口

## 三个已确认决策

1. 控制器代表色和排行榜颜色：以 UI 交付包为准。
2. 业务文案：以当前项目为准，`制动巡航` 不改为 UI 包中的 `自动巡航`。
3. 业务判断处的颜色规则：以 UI 交付包为准。

## 前端还原要求

- 使用 UI 包的 `tokens.css`、`styles.css`、`assets/icons/*.svg` 和截图作为视觉依据。
- 不引入 UI 包中的 `data.js`、`icons.js`、`render.js` 作为生产代码。
- 不使用浏览器 DOM 写法，不使用 `window` / `document` / `innerHTML`。
- 将 UI 包中的主题变量转译为当前小程序 `.app` / `.app.light` 可用的 TTSS 变量。
- 图标形状采用 UI 包交付的 SVG。由于小程序 `<image>` 不继承 `currentColor`，生产资源使用固定 stroke 色的多状态 SVG 变体，并由页面数据按明暗模式 / 选中态切换路径。
- 软件和手感模块的 good / warn / bad 颜色映射按 UI 包调整。
- `brakeCruise` 字段和现有逻辑保留，页面展示文案继续为 `制动巡航`。
- 产品色和排行榜条形颜色按 UI 包更新。

## 当前实现记录

- UI 包中的主题色、背景、面板、边框、文字、语义色已转译到 `pages/controller-review/index.ttss`。
- UI 包中的产品色已更新到 `pages/controller-review/index.js`。
- UI 包中的业务颜色判断已更新到 `textTone(colKey, val)`，并保留现有 `制动巡航` label。
- UI 包 SVG 已替换到 `assets/icons/`。生产资源采用固定 stroke 色的多状态变体，包括默认、明亮、主色选中、明亮主色选中和排序文字色，不再依赖 CSS `filter` 给 SVG 变色。
- UI 包中的浏览器预览脚手架未进入生产代码。
- 当前自动验收入口为 `node scripts/verify-v1.1.4-ui.js`，会生成多状态预览图用于对照。
- 默认首页状态已按 UI 包处理：最佳徽章和排名角标默认关闭，用户点击顶部按钮后再开启。
- 顶部排名角标按钮使用 UI 包的 `columns.svg` 图标形状，保持与 UI 状态稿一致。
- 表格 / 排行切换按钮未选中态为透明底和次级灰字，避免暗色模式出现小程序原生白底。
- 排序按钮上下箭头已增加明暗两套跟色规则，使箭头颜色接近“升序 / 降序”文字色。
- 抖音原生“反馈 / 三点 / 关闭”按钮不属于页面 TTML 节点，不能用页面 CSS 单独换肤；当前通过 `tt.setNavigationBarColor` 和 JSON 默认配置控制黑暗模式原生导航栏为 `#0E1623` / 白色前景，明亮模式保持 `#FFFFFF` / 黑色前景，并在 `onLoad`、`onShow`、主题切换后同步。
- 右上角平台胶囊按钮由抖音统一下发，不作为 UI 自绘组件落地；前端只保证其所在导航栏背景与前景黑白模式正确。
- 表格固定型号列已提高层级，并将高亮状态的型号列底色改为计算后的不透明实色，避免高亮产品后横向滑动时右侧数据文字透到型号列上。

## UI 交付覆盖

UI 侧已交付可打开预览的静态 HTML + CSS 状态稿，并覆盖以下状态：

- 深色模式
- 明亮模式
- 弹窗状态
- 表格横向滑动状态
- 排行榜状态
- 排序状态
- 选中态
- 图标状态
- 组件状态总览
- 375px / 390px / 400px / 430px 移动端宽度检查
