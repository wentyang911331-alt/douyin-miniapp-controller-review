# UI 图标体系方案

## 结论摘要

本项目图标统一采用「圆角容器 + 圆角线性图形」体系。图标本体使用线性 SVG，所有线条端点和拐角保持圆润；所有可点击图标放入圆角按钮容器中，避免继续混用文字符号、尖角箭头和不同视觉重量的图形。

本方案只覆盖保留功能：主题切换、最佳徽章、排名角标、列显示、排序默认、排序升序、排序降序、模块信息、关闭弹窗。

聚焦模式、录制功能、截图功能已确认移除，不设计入口和保留图标。

## 图标清单

| 图标 | 用途 | 建议图形 | 文案/无障碍名称 |
| --- | --- | --- | --- |
| 主题切换 | 顶部工具栏切换深浅色 | 圆角方块内的半月/太阳组合 | 主题 |
| 最佳徽章 | 控制是否显示最佳标记 | 圆角奖章/星标 | 最佳徽章 |
| 排名角标 | 控制是否显示表格排名 | 圆角编号标记 | 排名角标 |
| 列显示 | 模块内打开列选择 | 三列圆角竖条 | 显示列 |
| 排序默认 | 可排序列未选中状态 | 上下双箭头 | 默认排序 |
| 排序升序 | 当前列升序 | 向上箭头 | 升序 |
| 排序降序 | 当前列降序 | 向下箭头 | 降序 |
| 模块信息 | 模块标题旁打开说明浮窗 | 圆角信息 i | 说明 |
| 关闭弹窗 | 关闭说明浮窗 | 圆角 X | 关闭 |

## 视觉规则

- 图标容器：30px x 30px，移动端可点击热区不小于 32px x 32px。
- 容器圆角：8px；小徽章类可用 6px。
- 图标画布：20px x 20px，居中放置。
- 线条粗细：1.8px 至 2px。
- 线条端点：`stroke-linecap: round`。
- 线条转角：`stroke-linejoin: round`。
- 默认状态：低强调边框 + 页面次级背景。
- 激活状态：主色边框 + 主色浅底 + 主色图标。
- 禁用状态：透明度 0.38，不响应点击。
- 不使用 emoji、纯文本箭头、星号、井号作为最终图标。

## 状态规则

- 主题切换：始终显示一个图标，点击后只改变状态，不改变按钮尺寸。
- 最佳徽章：关闭时为默认态，开启时为激活态；表格内「最佳」标签使用圆角胶囊样式。
- 排名角标：关闭时为默认态，开启时为激活态；表格行内角标使用圆角小编号。
- 列显示：列面板关闭为默认态，展开为激活态。
- 排序默认：未排序列显示弱化的上下箭头，不抢表头文字。
- 排序升序/降序：当前排序列使用激活色箭头，并保持列标题宽度稳定。
- 模块信息：放在模块标题右侧或标题末尾，使用次级按钮样式；点击打开浮窗。
- 关闭弹窗：位于浮窗右上角，使用圆角按钮，触控热区不小于 32px。

## 移动端注意事项

- 顶部工具栏图标保持一行横向排列，必要时缩小间距，不压缩图标本体。
- 模块标题和信息图标应同行展示；标题过长时标题换行，信息图标不被挤压。
- 表头排序图标不得造成列宽跳动，默认、升序、降序都预留同等宽度。
- 小浮窗关闭按钮应固定在浮窗右上区域，避免被长说明文本挤走。
- 颜色不能只依赖色相表达状态，激活态还需要边框、底色或字重变化辅助识别。

## 需要主控/用户确认

- 主题切换图标采用「半月」还是「太阳/月亮组合」。
- 最佳徽章是否继续显示文字「最佳」，或改成「星标 + 最佳」组合。
- 排名角标是否保留 `#1` 文本，还是改为纯编号圆角标。
- 图标主色是否沿用当前页面主色，还是为测评报告风格指定更稳重的强调色。

## 前端接入建议

- 建议将图标集中定义为 `icons` 配置，不在页面各处散落字符。
- SVG 使用统一模板：`viewBox="0 0 20 20"`、`fill="none"`、`stroke="currentColor"`。
- 图标按钮统一使用同一个基础类，例如 `icon-btn`；状态只通过 `active`、`disabled` 等类切换。
- 后续迁移抖音小程序时，图标可转为内联 SVG 片段、图片资源或 TTML 可接受的等价结构。
- 当前原生抖音小程序生产实现使用 `<image>` 加载 SVG。由于 `<image>` 不能可靠继承 `currentColor`，运行资源采用固定 stroke 色的多状态 SVG 变体，并通过数据字段切换路径，不依赖 CSS `filter` 变色。
